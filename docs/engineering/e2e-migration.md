## Rust candidates

All 100 tests in the nine candidate files were classified individually below. No
native candidate was deleted or relabeled as a completed migration. **Pending**
means its complete CLI assertion set still resides in Rust. **Retained native**
means the named API/process/OS boundary remains native evidence; where the row
also says CLI, that portion is still pending readable migration. The first Python
reading set does not claim all repository E2E coverage.

Each row retains the linked original test as its execution owner. Existing
negative fixtures remain unchanged. No new RED is claimed for these retained
tests; their current execution evidence is the full `mise run test` log referenced
in [the delivery record](e2e-verification.md). The new current-entity scenario
additionally covers the first file-read test's exact closed JSON assertion; the
native copy is retained with the remainder of that matrix.
