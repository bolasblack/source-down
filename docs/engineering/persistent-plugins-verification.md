# Persistent plugin acceptance

This record tracks the 2026-09-07 implementation of persistent protocol v1 sessions on Linux x86_64 GNU. The crate remains 0.1.0 and project configuration remains version 1. The [initial release record](verification.md) preserves its own historical measurements. Product requirements belong to [the specifications](../specs/README.md); [AGD-009](../../.agents/decisions/AGD-009_own-persistent-plugin-processes-in-one-session-driver.md) records lifecycle ownership, and [AGD-010](../../.agents/decisions/AGD-010_keep-decisions-self-contained-and-separate-lint.md) records AGD independence and task separation.

## Regression development

The first process test failed because the host's initial message lacked `type`. The Session test first failed because the public session API did not exist. Missing include dependencies, dependency-only output protection, Python module inventories and Rust spec inventories each produced an observed failing boundary test before implementation. Strict Python framing tests rejected unterminated messages, duplicate keys and non-integer version forms only after a failing run exposed the gaps.

Full-suite execution also exposed a diagnostic teardown gap: observing stdout EOF could discard stderr bytes already buffered in the pipe. The process owner now stops writers and drains available stderr during cleanup while retaining a bounded tail. A public session regression demonstrated missing batch identity on semantic failures; contextual errors now preserve the error code, batch and request location.

Archive acceptance failed on the checkout's `CLAUDE.md` symlink to `AGENTS.md`. A real-archive regression reproduced that failure. Extraction now uses Python's `data` filter, preserving internal links and executable files while rejecting escaping links and special files. Explicit rejection of absolute or parent-traversing member names remains in place; the standard library owns destination and link confinement.

The replaced process exchange's protections remain owned by the driver, result validator and publication boundary: all three pipes progress, writes remain subject to deadlines, protocol and content faults clean process groups, direct children are reaped, descendants cannot indefinitely hold close open, and CLI success includes explicit close. One batch counter provides protocol identity. Phase timers enforce the configured limits; the poll interval permits command/cancellation observation during idle; symlink traversal bounds reject filesystem loops; file protection derives from actual inputs and declared dependencies.

## Measurements

Each enabled external plugin initialized exactly once for three batches of 500 requests. All resulting Markdown bytes matched the CLI baseline. Timing includes prepare/publish per round; explicit close is recorded separately.
