# Source Down v0.1.0

2026-09-17

## Highlights

Source Down's first release weaves explanations, source code and project material into traceable Markdown. Write in Markdown or six supported programming languages, keep the reading output current with watch mode, and search or read the original source ranges from the CLI. Project plugins supply their own content and checks through a versioned process protocol.

## Changes

- **Literate source and navigation**: Render Markdown, Rust, OCaml, JavaScript, TypeScript, Go and Python while preserving source bytes and locations; include files, sections or declarations, and link generated pages from inline or standalone directives. ## Contracts

- `docs/specs/README.md`: Defines specification ownership, stable clause identities and public format versions.
- `docs/specs/model.md`: Defines the literate programming model, source provenance, ownership boundaries and the meaning of a successful run.
- `docs/specs/rendering.md`: Defines source classification, original-byte preservation, Markdown composition and source annotations.
- `docs/specs/directives.md`: Defines inline and standalone directive syntax, arguments, literal examples and source locations.
- `docs/specs/entities.md`: Defines structural declaration selection for all six source languages.
- `docs/specs/standard-directives.md`: Defines standard include selection and generated-page URLs.
- `docs/specs/plugins.md`: Defines the versioned plugin protocol, persistent sessions, composed content, dependencies and failure handling.
- `docs/specs/cli.md`: Defines command entry points, configuration, file selection, publication and watch recovery.
- `docs/specs/search.md`: Defines searchable snapshots, current-source checks, short handles and bounded snapshot or current-file reading.
- `docs/specs/project-directives.md`: Defines this project's spec directive and reference-coverage checks.
